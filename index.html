Kết Nối Firebase Dùng Chung

Đồng bộ Realtime: Khi ai thêm/xóa món, mọi người đều thấy ngay lập tức!

📖 3 bước cấu hình Firebase (Hoàn toàn Miễn phí):

  1. Vào Firebase Console ➔ Tạo Project mới.
  2. Vào Build ➔ Realtime Database ➔ Create Database (chọn chế độ Test Mode).
  3. Vào Project Settings (icon bánh răng) ➔ Kéo xuống mục Your apps ➔ Thêm Web App </> để lấy đoạn mã firebaseConfig.

💡 Bạn có thể dán cả đoạn const firebaseConfig = { ... } hoặc dạng JSON { "apiKey": "..." }.
